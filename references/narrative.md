# 构思与叙事

文章从作者真正想弄清或想分享的事开始。让读者看见问题，经历发现，再抵达更深的理解和感受。语言自然之外，材料的顺序、解释的分寸和作者的眼光共同决定文章是否值得读。

本页包含构思和表达方法；连贯的成文演示见 [叙事范例](narrative-examples.md)。

## 找到阅读的四种收获

构思时，从材料里找这些东西：

| 读者得到什么 | 从哪里找 | 怎样写进文章 |
| --- | --- | --- |
| 发现的快乐 | 出乎意料的区别、熟悉事物中没注意过的一面 | 先让人认出熟悉的部分，再揭示那个差别，及时满足好奇 |
| 新的知识 | 原因、机制、条件，以及容易混淆的概念 | 消化材料后重新解释，用事实、例子或演示让人跟得上 |
| 被理解的感受 | 一个熟悉的处境，一种有过却没说清的情绪 | 用准确的动作和措辞让人认出来，情绪可以先于结论出现 |
| 持续变化的节奏 | 事实、场景、问题、类比和凝练表达之间的切换 | 在容易停滞的地方安排新的发现或感受，调整松紧和篇幅 |

它们可以共同出现，也可以由其中一项撑起一节。知识解释可以有趣，感受也有独立价值，不必每段都变成一条知识。

把全文的亮点位置标出来，观察中间是否有长时间空白。长文可每约 500 字回看一次：这一段让人看见了什么？发现不必都写成金句，也不按字数造惊喜。先检查材料是否值得写，再调整分布。

## 开头给读者一个想知道的事

从以下入口里选材料最有力的一种：

- **具体场景**：某个人正在做一件事，却遇到了难处。时间、动作、环境中挑能解释难处的细节。
- **意外事实**：结果与常识或预期不同。把共同条件讲明白，让意外成立。
- **真实问题**：读者可能遇到过，或者一看到就想知道答案。问题要具体到正文能回答。
- **有分量的判断**：材料已经足够，直接给出发现，随后让读者看见它从哪里来。

例如讲视频画质：

> 今天介绍分辨率和码率。
>
> 明明已经选了 4K，草地怎么还是糊成一片？

第二句让人看到熟悉的操作与意外的结果。接下来应解释这个结果，不能铺几段“画质很重要”。

开头的任务是邀请读者进入问题。避免连续藏答案、重复问“你知道吗”，或用与正文无关的经历装出悬念。

## 用材料推动几次发现

采用逐级递进时，先试着规划至少三级。每一级都要有具体案例、观察或数字，使理解发生变化。递进可以同时发生在几个方向：范围扩大、数量变化、解释更深、观察角度改变。

构思时按顺序写下：

1. 读者起初以为怎样。
2. 第一份材料让他发现什么。
3. 沿着这个发现，还会产生什么问题。
4. 后面的材料怎样继续改变理解。

这是一种结构选择，材料不足时补充、缩小题目或换结构，不用三个近义结论凑层数。

接着画质的例子，递进可以是：

| 这一层 | 具体内容 | 读者新明白了什么 |
| --- | --- | --- |
| 从分辨率进入 | 4K 描述像素数量 | 像素多，不代表所有细节都保留了 |
| 解释细节怎么丢失 | 压缩需要在有限数据量内表示画面 | 清晰度还受编码与数据量影响 |
| 比较画面内容 | 同样的压缩设置下，乱动的草叶比静止墙面更难处理 | 同一套设置面对不同内容，表现也可能不同 |

盖住小标题，看正文是否仍在推进。只说“很重要、更加重要、尤其重要”，没有完成递进。

需要几个方向同时推进时，见 [便民地图的完整演示](narrative-examples.md#那张地图后来画出了校门)。每次扩大范围，都让新的具体难处出现，再让作者调整认识。数字的作用是呈现变化，不能只换成更大的数，却仍在重复同一个道理。

## 让长文章有局部起伏

长文可以沿一条主线展开多个相对独立的章节。每节给出足够上下文，让中途读进来的人也能明白正在讨论什么；开头接住需要继续回答的问题，结尾让人有所发现。

一种常用的完整弧线是：**引起兴趣 → 展开事情 → 呈现张力 → 用材料解释 → 抵达意义**。

| 阶段 | 写什么 | 编辑时检查什么 |
| --- | --- | --- |
| 引起兴趣 | 具体问题、场景或意外发现 | 读者知道为什么要继续看吗 |
| 展开事情 | 事情怎么发生，最初怎样理解 | 背景是否只留下当前需要的部分 |
| 呈现张力 | 实际困难、矛盾、悖论或预期落差 | 这份张力来自材料，还是作者刻意夸大 |
| 用材料解释 | 事实、数据、对照、动作与机制 | 读者能否据此理解前面的难处 |
| 抵达意义 | 这件事还让作者看到了什么 | 联系是否自然，感受是否有来处 |

这五个作用不必变成五个标题，也不必等长。评测可以先给结论，纪实可以先观察，随笔可以让一处细节慢慢显出含义。没有冲突就不编冲突。

章节之间用内容衔接。例如刚解释“数据量有限”，下一节就问“那为什么草地特别难压”；读者知道现在为什么讲这个，不必每节重新报题。

## 从细节走向意义

意义可以在两个尺度上展开：章节收束带来“这件事还有这一层意思”，全篇收束让人带走更宽的理解或感受。时间、记忆、归属、自由、热爱，都可以由具体材料进入。

用 **锚定 → 追问 → 架桥 → 落点** 把这段思考走完整。

### 锚定：从眼前哪件事出发

选一个具体事件、动作或现象。最好能指出它发生在哪里，有什么可观察的差别。“珍惜记忆”太宽，“照片里的笑脸还在，却忘了大家为什么笑”就有了起点。

找不到具体锚点时，先回材料，不急着寻找宏大的结尾。

### 追问：沿哪个方向想下去

挑作者确实在意的方向继续问，不必把下表都问一遍。

| 方向 | 可以怎样问 | 会打开什么 |
| --- | --- | --- |
| 时间 | 放到更长或更短的时间里，这件事有什么变化 | 短暂与长久、记录与消失、期待与当下 |
| 人的感受 | 为什么会害怕、依恋、觉得自由或想留下来 | 个人处境与其他人也可能有过的感受 |
| 反向视角 | 从远处看眼前，它变成什么；从宏大退回此刻，还能做什么 | 一次尺度变化，或一个可信的小出口 |
| 关系 | 这件事与另一件看似无关的事，哪里相连 | 被忽略的联系、新的观察方式 |
| 意义 | 如果它不在了，具体会少掉什么 | 作者真正珍惜的东西 |

### 架桥：让读者跟上视角的变化

把具体与抽象之间缺少的一步说出来。常用的桥有三种：

- **解释差别**：照片保留了笑的样子，没录下让人笑的那句话，由此去谈记忆留下了什么。
- **提出问题**：事情已经做完，为什么作者还在反复想某个过程？问题本身把注意力带过去。
- **寻找意象的对应**：让一个具体物件承载新的感受，并说明哪一点相似。

“其实、或许、说到这里”只负责转接，不能替材料凭空造联系。类比可以帮助理解和感受，不能单独证明因果。

### 落点：落到读者有感觉的地方

| 落法 | 怎样写 | 适合什么内容 |
| --- | --- | --- |
| 用具体承载宽广含义 | 回到一个物件、动作或意象，让它带着前文的新理解出现 | 记录、文化、人和世界的关系 |
| 从宏大回到微小 | 承认远处的问题，再回到此刻可感受或可完成的一件事 | 焦虑、挫折、过程与生活 |
| 留下开放的一步 | 用一个具体问题或未说尽的动作收住 | 没有唯一答案、希望读者继续想的内容 |

不以越高越好为目标。意义可以是对过程的热爱，也可以是一种终于说清的感受；不必都落成行为建议。

跨度较大时，先找到能带着读者走过去的具体联系，再选落法：

| 想走到哪里 | 中间怎样接上 | 完整演示 |
| --- | --- | --- |
| 从自然观察走向超出个人经历的时间 | 先说明长期记录让什么问题可以被对照，再由接续的笔迹走向后来的人 | [河流记录](narrative-examples.md#六十本记录里的一条河) |
| 从长远困境回到此刻的期待 | 承认难题未解，让已有约定引出眼前的动作和想见的人 | [修桌子](narrative-examples.md#下午三点朋友要来) |
| 从家庭习惯走向文化与未来 | 展示同一种做法怎样经过不同人的手，再沿着具体变化想象下一次传递 | [剪纸燕子](narrative-examples.md#下一只燕子会带什么回来) |

这些例子给出不同的过渡，不是指定的结尾主题。当前材料只支持一处小感受时，就把它写准；材料打开了更宽的问题时，也不必为了克制而提前收住。

### 连起来试一次

假设材料是“整理旅行合影，地方还记得，想不起大家当时为什么笑”。

锚点是保留下来的笑脸与忘掉的缘由。追问照片替我们留住了什么，没留住什么。用“地方还能找回，当时那句话却可能再也想不起”解释这个差别。最后回到照片旁边的一行字：以后也记下，是谁说了什么，把大家逗成这样。

同一组材料也可以开放收束：“下次再一起翻到它，会不会有人想起那句话？”前一种落在记录的小动作，后一种落在与同行者再次回想的期待。

写完盖住最后的感慨。前面的细节和联系能否让人想到那里？如果不能，补上缺少的桥，或落近一点。读者已经明白的地方可以留白；后文要继续，就应带来新的含义。

## 把发现写得可感

### 凝练一句值得记住的话

先把事情讲透，再寻找可以独立留下的一句话。常用四种方式：

- 并置两种感受或结果，让差别自己显出来。
- 承认现实，再说由此得到的理解。
- 用一个具体动作承载抽象感受。
- 留出未说完的一步，给读者回想的空间。

例如一篇关于整理录音的练笔，前文已经写到作者记下了话的内容，却漏听了说话人的停顿，可以收成：“那句话我记得，句子中间停了多久，我刚刚才听见。”它的分量来自前文，不靠“深刻、伟大”抬高。

放在揭示或收束的位置，需要强调时再加粗。若摘出来只剩一个放哪都能用的口号，就回去找当前材料中特有的判断。

### 用熟悉的事解释陌生概念

先找结构相似之处，再选生活中容易想象的东西。工具的取用、排队、整理物品、旅行路线都可以成为材料。

讲缓存，可以这样写：

> 拧下一颗螺丝还要用螺丝刀，就先放在手边。缓存也类似：用过的数据留一份，下次仍然有效，就直接取来用。

把对应关系接回概念后，继续解释必要机制。涉及失效、空间限制或一致性时，类比没有解释的部分仍要讲。熟悉、准确、有画面比新奇更重要。读者本来就懂的概念，不必再绕一次比方。

### 让设问承担作用

开头的问题吸引人进入；过渡的问题带到下一步；反直觉的问题揭示差别；开放的问题让人继续想。每个问句都应改变注意力或引出值得回答的内容。

“缓存存下来了就永远能用吗？”能够打开有效期和数据变化。“这难道不值得我们深思吗？”如果后面没有具体思考，直接删去。

### 切换时间和尺度

可以从过去走到此刻，从此刻望向未来，也可以从漫长变化切到一个短瞬间。关键是跨度带来了什么理解。

写一张旧地图时，可以比较地图绘制之时、作者初次走过之时和今天。写很远的焦虑时，可以退回今天能完成的一个动作。跨度来自材料或明确的想象，不随手编年代。

时间切换以后，要让同一个物件或问题继续可辨：旧纸样怎样来到孩子手里，今天的一行记录怎样供后来的人对照。只把“小小的此刻”与“漫长的岁月”并列，尚未说明两者为什么相关。

### 用对照显出差别

时间、尺寸、预期与结果、两种做法都可以并置。先给足共同条件，再指出变化。

方法文章可先展示读者熟悉的笨办法，让难处可见，再演示怎样改。反例要合理，不能故意写得荒唐来衬托方案。成效没有实测，就比较做法和机制，不编效果数字。

### 用场景承载问题

选择一项实际动作、一次对话或一个界面细节，说明当时为什么困住了人。感官细节只留与当前含义有关的部分；没有材料支持时，明确作为假设场景。

场景写完要接向问题。无关的深夜、咖啡、叹气，会让开头更长，不会自动让作者更真实。

### 给有用的规律命名

名称让读者容易记住反复用到的概念，定义和例子使它有内容。先按 [命名五问](writing.md#给概念命名前过五问) 判断必要性，再使用。词名不能替代解释，也不能靠一串“某某法”制造思想。

逐级递进与意义四步法见前文，和这些技法配合使用。按当前段落的需要选择，不要求每篇逐项露面。

## 让文体决定松紧

| 文体 | 展开方式 | 收束方式 |
| --- | --- | --- |
| 人文纪实 | 跟随观察、动作和环境，节奏可以慢下来 | 让一个新看见的细节承载情绪，保留余味 |
| 科技评测 | 先把问题说清，交代条件，以数据、机制和对照展开 | 给范围清楚的判断，也可以回到技术影响人的地方 |
| 经历与思考 | 从真实处境讲认识如何变化，允许困难和脆弱 | 说出得到的理解、仍未解的事或可信的下一步 |
| 哲理与展望 | 容许宽阔尺度与想象，用具体锚点保持可感 | 提出大问题，给有分寸的理解或开放收束 |

表格适合多项比较，前面告诉读者注意什么，后面指出最值得看的差别。叙述是文章的主体，列表用于真正并列的内容或步骤。

平常用连贯段落推进；关键揭示、情感变化或需要回味处，可以独立成句。段落长短由内容决定，全篇逐句断行会削弱这种停顿的作用。

## 让情感有来处

好奇表现为愿意继续问，不摆出早已看透一切的姿态。热爱可以通过反复留心的细节表达，不需要堆形容词。遇到困难先承认它，再寻找可信的出口；出口也可以很小，不强行写成圆满结局。

作者的判断与感受要有材料依据。别把他人的经历、想法或测试据为己有，引用与事实按文章需要标注。技巧服务于作者确实想说的话，不替作者制造一种人生观。
