# 句式诊断与改法

先理解句子在当前文章里做什么，再使用本页。下列例子都是表达演示；“可改成”是一种同义且适合语境时的选择。形式命中不等于错误，词语、标点和句式都有正常用途。

## 翻译腔要改到结构上

以一个自拟例句为例：

> We carried out an inspection of the wiring.
>
> 我们对线路开展了检查工作。
>
> 我们检查了线路。

中间一句把动作包成“检查工作”，再用“开展”推动它。最后一句让动作直接出现。检查时重点看谓语在哪里、谁在做事、修饰是否太长，不只换几个词。

英文也能写得简短，中文也需要复杂句。编辑依据是这句中文是否准确自然，不把欧化、长句和 AI 写作画等号。

## 标点与排版

| 可疑形式 | 怎样处理 | 应当保留的情况 |
| --- | --- | --- |
| 破折号连续接出评价、解释和金句 | 判断每处是补充、转折还是另一件事，改用相应标点或分句 | 对话中断、实际转折和需要悬停的语气 |
| 抽象词反复加引号 | 若只是给模糊词加重，改成具体说法 | 原话、术语界定、反讽及有意的特殊用法 |
| 每次术语都附英文 | 首次确有需要时解释，后面固定叫法 | 双语对照或必须区分的名称 |
| 一段多处加粗 | 找最值得留意的判断或数据，减少无差别强调 | 供回查的结构化标签 |
| 中文叙述夹半角标点 | 将叙述标点改为中文标点 | 代码、命令、英文、小数、千分位、路径与链接 |

例如“稿件已通过审核——也意味着所有准备工作圆满完成”，若审核并不代表准备全部完成，问题是结论过头；换标点救不了这句话。

## 句式

| 可疑形式 | 编辑动作与例子 | 判断边界 |
| --- | --- | --- |
| 反复“不是……而是……” | 找出成立的判断，直接说；已经交代的否定项不再重复 | 真正的纠错和对比要保留区别 |
| “既是……也是……更是……”不断叠加 | 分清究竟有几项不同含义，合并同义项 | 双重身份或并行功能确实不同 |
| “前者、后者”让读者回找 | 重复准确名称：“甲稿先讲原因，乙稿先给例子” | 对象近、指代一眼明确时可用 |
| “值得深思、不禁让人感慨” | 直接写思考所得，或让细节自己说话 | 讨论别人如何评价时按语义保留 |
| “我们不禁要问，这引出更深的问题” | 直接提出那个问题，少一层报幕 | 需要交代问题来由时保留解释 |
| “上述、该、此”连续回指 | 用“这个”或重复具体对象 | 正式条款和索引中确实有助定位 |
| 无必要的“被、由……所” | 人与动作相邻，或将对象放在句首沿着讲 | 遭遇、责任、施事未知或需要突出受事 |

例如“他的意见不被大家接受”，可写“他的意见，大家都不接受”。接受与否没变，做动作的人更直接。不要把“他被要求参加”改成“他主动参加”。

## 词汇与搭配

| 可疑形式 | 怎样改 | 例子或边界 |
| --- | --- | --- |
| 进行、作出、实现、完成后藏着动作 | 取出真正的动词，并保留完成状态或程度 | “进行了核对”→“核对了”；“作出承诺”未必需要改 |
| 化、性、型、度、属性只增加抽象 | 展开它要求做什么或描述什么 | “验证前置化”→“提前验证”；专业概念按定义保留 |
| “这一环节、这一过程、这一维度” | 若没有区分作用，直接说那件事 | “修改这一过程需要耐心”→“修改需要耐心” |
| 强调副词太多 | 给出重要在哪里或具体后果 | 不能把“较重要”夸大成“少了它一切都失败” |
| “深刻、震撼、显著”等空评价 | 用材料中已有的细节、差别或测量结果支持 | 没有数字就不补数字，没有场景就不编场景 |
| “有研究、专家认为”但无出处 | 找到具体证据；没有就撤去权威说法，收窄为可支持的判断 | 不能改成虚构的“我试过” |
| 同一对象轮流换名 | 选准确称呼贯穿全文，必要时重复主语 | 不为避免重复把产品、系统和团队混为一谈 |
| “当……的时候”拖长起手 | 若事件本身能表示时序，直接从事件写起 | “当铃声响起的时候”→“铃声响起”；条件和同时关系要保留 |
| 时间地点前层层加“在” | 去掉没有作用的介词，让时间地点直接进入 | “在昨天下午的会上”→“昨天下午会上”；“在这个问题上”可能必要 |
| “作为……”只是报身份 | 身份必要就直接说，与判断无关就略去 | 强调角色责任时，“作为负责人”有作用 |
| “是……的”给形容词加空壳 | 试着让形容词直接作谓语 | “页面是清楚的”→“页面很清楚”；“是昨天寄的”有强调作用 |
| “最……之一”含糊排行 | 明确比较范围，或保留有依据的原判断 | “最受欢迎之一”不能改成唯一“最受欢迎” |
| “一个／一种＋很长的修饰＋名词” | 先出现对象，再展开能力或条件 | “我们需要一个能记录修改并在出错时恢复旧稿的工具”→“我们需要一个工具，能记录修改，出错时恢复旧稿” |

动词和形容词还要与对象匹配。“流程生锈了”若只是想说流程已经不适用，就直接写明哪里不适用。文学比喻可以有意越过字面搭配，但必须让人理解它的对应，不能只取一个猛烈的词撑语气。

借译词先查读者是否熟悉、有没有更自然且同义的说法。面向普通读者，“截止时间”通常比“死线”直接；软件、进程、线程等已确立的术语照用。新名称按 [命名五问](writing.md#给概念命名前过五问) 检查。

## 段落结构

| 问题 | 怎样识别 | 怎样改 |
| --- | --- | --- |
| 段末反复宣布意义 | 每节都以“这充分说明……”结束，却没有新认识 | 让段落停在最后一个有效细节，新的意义则补足联系后保留 |
| 并列项为了凑数 | 几项合成一句，内容几乎不变 | 合并同义，留下各有作用的项目 |
| 每个判断都立即收回 | “当然、另一方面”只求姿态均衡，没给实际边界 | 先把判断说清，确有例外时交代条件与影响 |
| 宣称两件事“本质一样” | 只给标签，没有指出相似之处 | 说明共享的机制或区别；不能将相似直接改成因果 |
| 预告、讲述、复述三遍 | 开头说要讲什么，末尾又重复刚讲过什么 | 直接展开；确需导读或复杂结论汇总时保留其功能 |

同样是总结，重复“所以很重要”与把几条材料连成新认识，作用不同。判断依据是有没有新增理解，不是句子是否在段末。

## 反复的结构排比

从显眼的标题到句子里的小对称，都要看看形式是否替代了内容。

| 形式 | 示例特征 | 修改办法 |
| --- | --- | --- |
| 数量标题序列 | 第一刀、第二招、第三个维度只报次序 | 小标题写具体观点；步骤、规范与索引保留编号 |
| 分号或破折号串联多个判断 | 一句里连续换了几件事 | 按意义分句或列出真正的并行内容 |
| 连续“X 不 X” | 顺不顺、自然不自然、像不像人 | 将同义问题合并，保留确实不同的检查 |
| 翻案变体反复出现 | 你以为却其实、看似却实则、真正的是 | 直接写发现；保留产生理解变化的真实对照 |
| 成对句式反复重复 | 就该 A 就该 B、不必 A 更不必 B | 合并重复含义，改变确实需要变化的语气 |
| 三个以上名词或动作成串 | 清晰、明确、直白等近义词轮流出现 | 留最准确的表达；真实分类、步骤和有作用的修辞保留 |

例如“让表达更清晰、更明确、更直白”，若没有具体区别，可以写“让读者一遍看懂”。“核对日期、人物和引语”则是三项不同工作，不能为了减少并列删掉其中两项。

## 怎样决定修改幅度

少量字词问题，逐处处理。若一段反复出现名词化、长修饰和空泛评价，先用一句话写清段意，再按含义重写整段。命中密度可帮助选择范围，不能据次数直接删段。

改后回看事实与语气是否保持，再按 [编辑流程](editing.md) 检查节奏。表格给的是识别入口，不是禁词表，也不用于判定文章是否由 AI 生成。
